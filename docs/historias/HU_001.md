# HU_001: Registrarse como paciente

| Campo | Valor |
|---|---|
| Épica | 1. Cuenta |
| Actor | Visitante |
| Prioridad | Alta |
| Puntos de historia | 3 |
| Requisitos | RF_001 |
| Reglas de negocio | No aplica |
| Mockup | `docs/mockups/HU_001.png` |

## Historia

**Como** visitante de CitaSalud,  
**quiero** crear mi cuenta de paciente con mis datos personales y mi tipo de paciente,  
**para** poder agendar y administrar mis citas médicas.

## Validación INVEST

| Criterio | Cumple | Justificación |
|---|---|---|
| Independiente | Sí | Se puede desarrollar y probar sin esperar otras historias, salvo los datos que crea el administrador. |
| Negociable | Sí | Los detalles de pantalla y mensajes se pueden ajustar con el profesor. |
| Valiosa | Sí | Le da valor directo al visitante: poder agendar y administrar mis citas médicas. |
| Estimable | Sí | Alcance claro; estimada en 3 puntos. |
| Pequeña | Sí | Cabe en un sprint de una semana. |
| Testeable | Sí | Tiene criterios de aceptación verificables con pruebas y Postman. |

## Criterios de aceptación

```gherkin
# language: es
Característica: Registrarse como paciente

  Escenario: Registro exitoso
    Dado que soy un visitante sin cuenta
    Cuando ingreso nombre, documento, correo, teléfono, fecha de nacimiento, tipo de paciente y una contraseña de al menos 8 caracteres
    Entonces el sistema crea mi cuenta como paciente
    Y me muestra un mensaje de bienvenida

  Escenario: Correo ya registrado
    Dado que ya existe una cuenta con el correo "ana@correo.com"
    Cuando intento registrarme con ese mismo correo
    Entonces el sistema no crea la cuenta
    Y me informa que el correo ya está en uso

  Escenario: Datos incompletos
    Dado que soy un visitante
    Cuando dejo vacío el documento o la contraseña tiene menos de 8 caracteres
    Entonces el sistema no crea la cuenta
    Y me indica qué campos debo corregir

```

## Supuestos

- El tipo de paciente (Particular, Convenio o Prepagada) lo declara el paciente al registrarse.
- La contraseña se guarda cifrada.
